Sharp 把「学」和「练」拆成两条独立路径：Wiki 负责把知识讲清楚， 题库 负责把记忆留下来。你可以先读一篇，再去做对应练习。

建议第一次使用时，按下面的顺序走一遍。
4

第一步：准备账号

使用邮箱或第三方账号登录即可，学习记录会跟随账号同步，换设备不用重新开始。

  1. 完成登录，并在「偏好设置」里选择常用语言。
  2. 设置每日练习目标（建议从 20 题开始）。
  3. 在题库页收藏一个感兴趣的主题。
提示：收藏本页后，可在「我的收藏」里快速回到这份指南。

第二步：开始第一次练习

题库按主题组织，每一组练习都会记录正确率与用时，结束后自动生成复习清单。

// 练习配置示例
{
  "topic": "vocabulary",
  "size": 20,
  "mode": "daily"
}

一个小技巧

练习时不必追求速度：连续 3 天完成目标，比一次性刷 100 题更容易形成记忆。

目录展开态：全宽卡片浮层，最大高度 46vh 内部滚动；当前项与父级展开规则与桌面一致。

  • 5上下篇改为纵向堆叠，保持 44px 点击高度。

05

与当前实现相比改了什么

对照 wiki-browser.tsx 现状

差异清单 为什么改
区域现状设计稿原因
目录容器 透明裸列表，仅顶部分割线；跟随页面滚动消失 白卡 + 12px 圆角 + 阴影；sticky 常驻 长文滚动时仍可换页，目录本身成为可识别的导航区域
当前项 bg-primary-light + 文字变色 增加 3px 主色竖条，父级箭头常显 颜色之外多一层位置线索；展开状态不再靠 hover 才发现
标题区 面包屑 / 标题 / 摘要 / 更新时间均 mt-2，节奏偏平 0.5 / 0.7 / 0.7rem 递进；元信息合并为一行 + 标签 先看到「这是哪一页」，再看到「读多久、什么时候更新」
标题 ↔ 正文 1px border，且间距为 0（紧贴） 1px border-light，上下 1.5rem / 1.25rem 线不压文字；若坚持紧贴可把这两处间距改回 0（待确认）
正文容器 透明背景，通栏，无阅读宽度限制 白卡 + 1rem 内边距，正文阅读宽 778px 长文视线跨度过大；白卡与站内其它页面的卡片语言一致
上下篇 无 新增双卡，移动端堆叠 文档是链式阅读，缺省出入口会打断连续浏览
移动目录 「目录 / 收起目录」按钮，展开后列表插在正文上方 sticky 目录条（带当前页名）+ 浮层卡片 滚动中随时换页；收起后不占正文空间
待确认项（评审时拍板）
  • 标题分隔线的呼吸感：设计稿给 1.5rem / 1.25rem；上一轮线上要求「紧贴」，两种方案只差这两个数值。
  • 右侧「本页大纲」：≥1280 时可加 200px 栏，锚点跟随滚动；会增加三栏复杂度，本稿未画。
  • 目录搜索：节点超过 30 篇时建议加过滤输入框，当前先不做。
  • 术语：「目录 / 本页大纲 / 相关页面」沿用现有 i18n 词条，不新增文案。
落地映射（仅供参考，本次不实施）
  • 目录卡：wiki-browser.tsx 的 aside 外层加 rounded-xl border bg-surface card-shadow，栅格改为 lg:grid-cols-[15rem_minmax(0,1fr)] gap-8。
  • 正文卡：article 加卡片样式与 p-4（四周统一 1rem，舒适档 20px，随密度缩放）。
  • 标题区：面包屑、h1、摘要、元信息之间的间距统一为 rem，分隔线改 border-light。
  • 上下篇：需要接口提供相邻节点，或在前端按 tree 顺序推导（树已包含全部节点）。
  • 评审后修订：页面去掉纵向内边距（仅留 0.25rem 贴边缓冲），正文卡内边距统一 1rem（20px），左卡 sticky 改为 top: 3.5rem，保证两卡顶边 0px 差值。
设计稿为静态 HTML，未引入外部依赖与图片资源；示例配图使用虚线占位块，正式实现沿用后台富文本产出的图片。 颜色、圆角、阴影均来自 apps/web/src/app/globals.css 现有令牌；正文排版沿用 .article-content 的字号与间距规则。 本稿不修改 apps/web 下任何代码。
