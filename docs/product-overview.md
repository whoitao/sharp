# Sharp 产品概述

## 一、产品定位

Sharp 是一款面向 **K12 学习与备考场景**的多端学习产品，以结构化题库为基础，将教材同步练习、知识点专项训练、学习数据分析和宠物成长激励相结合，帮助学生建立“学习—练习—反馈—复习—持续提升”的完整学习闭环。

产品覆盖小学、初中和高中阶段，支持多学科内容，可服务于课前预习、课堂同步、课后巩固、阶段复习及专项查漏补缺等场景。用户既可以通过 Web 浏览器学习，也可以使用 iOS、Android 移动端，管理员则通过独立后台维护学习内容与平台数据。

## 二、核心功能

### 1. 贴合实际教材的内容体系

题库按照学段、年级、学科、教材版本、册次和章节进行组织，使学习内容能够与课堂进度对应。同时建立树状知识点体系，并支持知识点与题目多对多关联，为系统化学习和针对性训练提供统一的数据基础。

### 2. 章节与知识点双路径学习

用户可以根据自己的学习目标选择不同路径：

- **按章节学习**：沿教材结构逐章、逐节练习，适合同步课程和系统复习。
- **按知识点学习**：围绕具体知识点集中训练，适合专项突破和查漏补缺。
- **灵活练习设置**：支持调整每组题量、学习范围和展示方式，兼顾不同学习节奏。

答题过程中提供结果反馈与解析，并结合收藏、错题回顾和学习记录，帮助用户及时发现问题、重复巩固。

### 3. 学习结果分析

产品持续记录用户的答题数量、正确率、完成情况和知识点表现，通过学习统计、结果分析与排行数据，直观呈现学习成果和薄弱环节，为后续复习提供依据。学习数据不再只是单次成绩，而是可持续追踪的个人学习档案。

### 4. 宠物陪学与成长激励

将长期学习与宠物养成结合，用户通过学习获得成长反馈，宠物随学习过程呈现不同阶段、动作和互动状态。该机制把相对枯燥的重复练习转化为可感知、可期待的成长过程，增强学习的趣味性和持续性。

### 5. 个性化与多语言体验

支持简体中文和英文界面，提供 Dark、Light 主题，并支持学习范围、正文展示、题量等个性化设置。账号体系涵盖个人资料、头像、学习偏好和消息通知，使用户能够在不同设备上获得一致的学习体验。

### 6. 内容与用户服务

除题库练习外，产品还提供文章、Wiki 知识内容、通知和反馈等能力，便于承载学习方法、知识说明、平台公告及用户问题，逐步从单一答题工具扩展为综合学习平台。

## 三、管理与运营能力

Admin 后台提供用户、管理员、题库、教材、章节、知识点、文章、Wiki、宠物、通知和反馈等管理功能。富文本编辑器支持图片、表格、数学公式、代码块等内容形式，并支持题目导入及结构化维护，降低内容生产和持续运营成本。权限管理机制可区分不同管理员职责，保障平台数据和操作安全。

## 四、产品价值

Sharp 的核心价值不只是“提供更多题目”，而是通过教材与知识点双体系提高练习的针对性，通过真实学习数据提升复习效率，再通过宠物成长机制增强长期学习动力。三端共享统一账号、内容和数据，使用户能够随时学习，也使内容维护、学习反馈和平台运营形成完整闭环。
